# KubeMetal

[English](README.md) | 한국어

KubeMetal은 Apple Silicon Mac에서 Kubernetes 및 하이브리드 MLOps 워크로드를 관리하고 가속하기 위한 데스크톱 대시보드 및 운영자 도구입니다.

## 주요 기능

- **Apple Silicon Metal 가속 지원:** 로컬 Metal GPU/Neural Engine 기반 AI/ML 워크로드 모니터링
- **Kubernetes 플릿 관리:** 클러스터 노드 상태 및 컨테이너 런타임 제어
- **데스크톱 네이티브 성능:** Rust(Tauri) 및 React 기반의 경량화된 운영자 UI

## 빠른 시작

```bash
# 의존성 설치
pnpm install

# 데스크톱 개발 모드 실행
pnpm tauri dev
```
