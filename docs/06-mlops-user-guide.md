# KubeMetal MLOps 사용자 가이드 (실습 중심)

KubeMetal은 **"macOS Apple Silicon의 초고속 GPU(Metal)"**와 **"Kubernetes 기반 클라우드 MLOps 생태계"**를 결합한 하이브리드 파이프라인 시스템입니다.

MLOps가 처음이시더라도, 아래 **4단계 시나리오**를 따라 실행하시면 엔드투엔드 파이프라인(데이터 준비 → 오케스트레이션 학습 → 자동 채점/평가 → 모델 서빙 & RAG)을 손쉽게 정복하실 수 있습니다.

---

## 💡 한눈에 보는 핵심 개념 (3개 축)

1. **Host (macOS) - 연산 엔진**: GPU/NPU를 풀로 사용하는 MLX 파인튜닝, 로컬 모델 서빙(`mlx_lm.server`), LanceDB 벡터 인덱싱
2. **K3s (Virtual Machine) - MLOps 제어면**: 
   - **Prefect 3**: 작업(학습, 평가)을 순서대로 실행하고 관리하는 파이프라인 관리자
   - **MLflow**: 학습 결과(Loss), 평가 점수(MMLU/GSM8K), 모델 아티팩트를 기록하는 실험 기록장
   - **SeaweedFS**: S3 호환 데이터/모델 중앙 저장소
3. **KubeMetal App (Tauri) - 중앙 콘솔**: 이 모든 복잡한 명령을 UI 버튼과 탭으로 제어하는 대시보드

---

## 🚀 실습으로 배우는 4단계 MLOps 사용법

### 1단계: MLOps 인프라 켜기 (`대시보드` 탭)
1. **Colima K3s 클러스터 시작**: `대시보드` 탭에서 **[클러스터 시작]**을 누르면 가상머신 내 Kubernetes가 기동됩니다.
2. **MLOps 스택 프로비저닝**: **[스택 프로비저닝]** 버튼 클릭 한 번으로 MLflow, SeaweedFS, Prefect 3 파드가 자동으로 K8s에 배포됩니다.
3. **포트포워딩 시작**: **[포트포워딩 시작]**을 누르면 K8s 내 서비스(MLflow 5001, Prefect 4200, SeaweedFS 8333)가 로컬 macOS로 연결됩니다.

---

### 2단계: 모델 준비 & 데이터셋 버저닝 (`모델 허브` & `파이프라인` 탭)
1. **모델 다운로드**: `모델 허브` 탭에서 HuggingFace의 경량 모델(예: `Qwen2.5-0.5B-Instruct`)을 검색하고 다운로드합니다.
2. **DVC 데이터셋 버저닝** (`파이프라인` 탭 하단 `DVC 카드`):
   - 내가 모은 학습 데이터셋이나 지식 문서를 관리합니다.
   - 태그 이름(예: `v1.0-dataset`)과 설명을 입력하고 **[버전 태그 생성]**을 누르면, 데이터의 변경 이력이 SeaweedFS S3 저장소에 안전하게 기록됩니다.

---

### 3단계: Prefect 파이프라인으로 "자동 학습 & 자동 채점" (`파이프라인` 탭)

MLOps의 핵심은 **"클릭 한 번으로 학습부터 평가까지 자동화"**하는 것입니다.

1. **Prefect 플로우 러너 기동**: `파이프라인` 탭 상단 `Prefect 카드`에서 **[시작]**을 눌러 플로우 러너를 실행합니다.
2. **파인튜닝 플로우 트리거**:
   - `[파인튜닝 실행]` 버튼을 누르고 다운로드한 모델을 선택합니다.
   - Prefect가 macOS Host의 Apple Silicon GPU를 구동하여 파인튜닝을 수행하고 완료 상태(`COMPLETED`)를 모니터링합니다.
3. **모델 서빙 기동**: `MLX 스튜디오` 탭에서 만들어진 어댑터/모델을 선택 후 **[서빙 시작]**을 누르면 `:8080` 포트에 OpenAI 호환 API가 기동됩니다.
4. **자동 평가(Evaluation) 수행**:
   - `Prefect 카드`에서 `[평가(lm-eval) 실행]`을 클릭합니다 (기본 과제: 수학 추론 `gsm8k`).
   - Prefect가 `lm-eval` 채점기를 돌려 서빙 중인 내 모델에 문제를 풀게 하고 점수를 매깁니다.
   - **결과 확인**: 채점된 exact match 점수가 MLflow에 자동 기록되며, `MLflow UI` 버튼을 눌러 그래프로 확인할 수 있습니다.

---

### 4단계: 내 문서로 똑똑해지는 로컬 RAG (`파이프라인` 탭 `RAG 카드`)

파인튜닝한 모델이 내 개인 문서/사내 문서의 내용을 참조해 답변할 수 있도록 지식 베이스를 구축합니다.

1. **문서 인덱싱**: `RAG 카드`에서 내 마크다운/텍스트 문서가 있는 폴더 경로(기본값: `docs`)를 입력하고 **[인덱싱 시작]**을 누릅니다.
   - LanceDB 벡터 데이터베이스가 디스크 기반으로 아주 가볍게 문서 임베딩을 생성합니다.
2. **시맨틱 검색 테스트**: `시맨틱 검색 테스트` 창에 질문(예: *"Prefect 오케스트레이션 구조는?"*)을 입력하고 **[검색]**을 누르면 문서에서 가장 관련 높은 구절과 유사도(Score)를 즉시 뽑아줍니다.

## 🛠️ 상황별 사용 가이드 (Cheat Sheet)

| 하고 싶은 작업 | 이동할 탭 | 실행할 버튼 / 작업 |
|---|---|---|
| MLOps 서버/인프라 정상인지 확인 | `대시보드` | 서비스 포트포워딩 상태 및 CPU/RAM 모니터링 |
| 새 LLM 모델 다운로드 | `모델 허브` | HuggingFace 검색 후 [다운로드] |
| 모델 파인튜닝 (학습) | `MLX 스튜디오` 또는 `파이프라인` | `[파인튜닝 시작]` 또는 Prefect `[파인튜닝 실행]` |
| 내가 파인튜닝한 모델 성능 테스트(채점) | `파이프라인` | 서빙 기동 후 Prefect `[평가(lm-eval) 실행]` |
| 학습 기록 / 평가 점수 그래프 확인 | `파이프라인` 또는 `접근성` | `[MLflow UI]` 링크 클릭 (http://localhost:5001) |
| 사내/개인 문서 벡터화 및 검색 | `파이프라인` | `RAG 카드`에서 `[인덱싱 시작]` 및 `[검색]` |
