# Spacing

4px 스케일. Tailwind 기본 spacing(0.25rem=4px 단위)과 1:1로 일치하므로 별도 오버라이드 없이 숫자 유틸리티(`p-6`, `gap-3` 등)를 그대로 쓴다. `design-tokens.json`의 `spacing`은 문서화 목적의 참조값이다.

## 간격 리듬

| 용도 | 값 | Tailwind 클래스 |
|---|---|---|
| 인라인 아이콘-텍스트 갭 | 8px | `gap-2` |
| 배지/버튼 내부 인라인 갭 | 12px | `gap-3` |
| 카드 패딩(기본) | 24px | `p-6` |
| 서브 카드 패딩 | 16px | `p-4` |
| 카드 내부 요소 간 세로 간격 | 16px | `space-y-4` / `mb-4` |
| 섹션(카드) 간 간격 | 24px | `gap-6` / `space-y-6` |
| 페이지 좌우 여백 | 24px | `px-6` |
| 페이지 최대 폭 | 1280px | `max-w-7xl mx-auto` |

## 규칙

1. 카드 패딩은 항상 `p-6`(24px)로 통일한다. 카드 내부의 서브 카드(메트릭 블록 등)만 `p-4`(16px)를 쓴다. 임의의 `p-5`, `p-3.5` 등 중간값 사용 금지.
2. 대시보드 최상위 섹션 간 간격은 `gap-6`/`space-y-6`으로 고정한다.
3. 모든 페이지 콘텐츠는 `max-w-7xl mx-auto`로 폭을 제한해 넓은 화면에서도 줄 길이가 과도해지지 않게 한다.
4. 그리드 정렬: 카드 그룹은 `grid grid-cols-1 md:grid-cols-2` 또는 `md:grid-cols-3`처럼 반응형 컬럼을 명시하고, 갭은 항상 `gap-4`(카드 내부) 또는 `gap-6`(최상위)만 사용한다.
